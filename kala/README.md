# Kala Events website

Two versions of the same site:

- `plain/`  – HTML + CSS + JS. Open index.html in VS Code (Live Server) or host on GitHub Pages.
- `react/`  – React + Vite. Run `npm install` then `npm run dev`. Build with `npm run build` (output in dist/).

## Photos
Add your own JPGs in `images/` (plain) or `public/images/` (react) using the names in the README.txt there.
Until a photo exists, a colour gradient shows instead, so the site never looks broken.
Tip: use real photos from your past events, 1600px wide, under 400 KB each.

## Edit content
- plain: edit index.html
- react: edit the lists at the top of src/App.jsx (prices, services, phone numbers)
